Диалог с ассистентом
Общение напрямую на компьютере. История сохраняется локально; подключение MAX не требуется.
Экспорт персональных данных
Личная память, база знаний и диалоги с приватным контекстом обрабатываются локально. Для облака используйте отдельный диалог без приватных данных.
Текущий запуск
Голос
Аудиофайл до 20 МБ и 5 минут распознается локально. Голосовой ввод не выдает права на инструменты. Озвучивание использует установленный TTS и подготовленный профиль; текст остается доступен.
Результат
Результат появится после выполнения задачи.


Папки знаний
Явно выбранные папки: TXT, Markdown и PDF с текстовым слоем (requirements-rag.txt). Изменения индексируются worker в фоне. Скрытые файлы и символьные ссылки пропускаются. Удаленный через панель документ автоматически не возвращается.
База знаний
Загрузите TXT или Markdown до 512 КБ. Текстовый поиск доступен сразу; смысловой поиск включается при настройке локальной модели эмбеддингов.

Личная память владельца
Общие факты для панели и подтверждённых личных чатов MAX и Telegram. «Запомни» сохраняет факт, «Забудь» удаляет его из общей памяти. Пароли и ключи не сохраняются.


Исходники проекта
Рабочие файлы доступны для просмотра. Правки сохраняются в отдельной копии; применение требует успешных тестов и проверки diff.
Diff и проверки


Системные фоновые сервисы
Сводки, проверка настроения и уведомления используют общую очередь доставки и настроенного получателя MAX. Включение разрешает последующие фоновые доставки.
Новая автоматизация
Результат появится отдельным диалогом в панели. Выполнение локальное, без инструментов. После простоя можно пропустить запуск или выполнить один раз; параллельные запуски одного расписания исключены.


Привязка каналов
Создайте код, отправьте команду боту из нужного чата, затем проверьте ID отправителя и чата и подтвердите привязку. Подтверждение даёт личному чату доступ к общей памяти. Привязку к истории диалога и его документам можно выбрать отдельно. Права на инструменты привязка не выдает. Используйте личный чат.


Реестр моделей
OpenAI-совместимые endpoints. В key_env укажите имя переменной *_API_KEY из приватного окружения. Для автовыбора задайте intents (имена намерений или default) и priority. timeout_seconds и cooldown_seconds ограничивают обращение и паузу после сбоя. Тарифы — за миллион токенов, daily_budget — суточный расчетный бюджет (0 отключает лимит). Расчет до запроса использует консервативную оценку по UTF-8 и максимальный ответ, включая неуспешные HTTP-вызовы. Валюта тарифов должна совпадать.
